00 / FORMULA MODE

配合選定モード

v4準拠モードは毛質・くせ・水軟化・施術履歴で表を参照。アルギニンモードでは毛髪条件に応じてアルギニンが必要な部位のみ配合します。ACが不要な部位は0%です。必要時の上限率は1〜3%の試験範囲で設定します（初期表示2%、最適量を意味しません）。クエン酸は任意で、pH・ACは実測値で確認します。くせの列はドライ／ウェットの強い方を使用。Lv6・著しい強度低下・ブリーチ毛の水軟化（強）は自動停止。v4は5段階のためLv5はブリーチ表に対応します。既矯正毛は専用表の太毛・普通毛・細毛列で選定します。

01 / HAIR DIAGNOSIS

3ゾーン毛髪診断・自動予測

ドライのくせは「チオ系」、ウェットのくせは「システアミン系」の寄与を検討するためのGT独自の仮モデル。薬剤成分の分類は下の設定で確認・修正してね。自動処方は検証前の参考候補です。Lv3以降はHを抑え、LA・低アルカリコスメを優先します。v4掲載の異なる製品区分の組み合わせは参考候補として表示し、メーカー混合可否の確認を必須とします。

03 / ARGININE-FIRST FORMULATION · TEST MODE

★ 新配合を自動作成｜アルギニン必要時のみ・TG最優先

このモードではv4の毛髪条件別ACを基準にアルギニンの要否を判定します。AC記載なし・低ACでは添加せず、必要と判断した場合だけ候補として配合します。添加率を入力すると、根元・中間・毛先の総量からアルギニン重量を先に確保し、残量をTG目標に近づくよう低ACのut-et薬剤から再選定します。クエン酸100%粉末は必要な部位のみ任意で入力できます。入力値は推奨量ではなく試験設計用です。添加後のAC・pHは実測するまで未確認です。異なる製品区分の混合候補も表示されるため、メーカーの混合可否確認が必要です。

毛髪条件・v4 ACで部位ごとに0〜上限率を自動判定。メーカーの混合可否・溶解性・毛束試験を確認してください。
【試験設計専用】アルギニンの必要性判定と添加率はv4 ACを使った仮ルールであり、実測データに基づく最適量ではありません。アルギニンとクエン酸の添加によるAC・pHの変化は計算で保証できません。pHとACは別の指標です。実測値がない場合は「未確認」と表示し、著しい強度低下などの自動停止条件は維持します。
04 / INGREDIENT PROFILE

薬剤の還元剤分類を確認

下の「チオ系／システアミン系」は計算の振り分け用。初期値は仮分類で、実際の製品成分を確認するまで施術用の確定処方には使わないでください。両方を含む製品は「両系」に変更できます。

05 / REFERENCE

計算方法と注意点

TG換算値・AC（アルカリ度）は、登録した単剤スペックを重量比で加重平均した参考計算値。混合後のpHは算出できないため「要実測」と表示します。ドライ／ウェットのくせから還元剤を一意に決定できる科学的に確立された法則はなく、ここでは美容師が調整するための仮説モデルとして扱います。異なる製品区分（医薬部外品と化粧品）の混合はメーカーの使用条件を確認してください。著しい強度低下・ビビリ毛は自動選定を停止します。強度が弱い／不明・Lv5は要確認の参考配合のみ表示します。健康毛・太毛硬毛・強いくせではSHを候補に含めます。ネントは毛髪履歴とダメージから0・10・20%の検証用配合候補を自動追加しますが、配合率はメーカー推奨値ではありません。ブリーチ・高ダメージかつ強度良好の場合はネント10%を検証用候補として表示します。混合後AC0は保証できません。クリームのTG換算・ACなどの検証済み数値がないため、表示するTG・ACはut-et部分だけの計算値で、混合後の数値ではありません。ブリーチ履歴で強度が保たれている場合はAC 0の候補のみ表示しますが、施術可能との判断ではありません。配合候補は安全性・仕上がりを保証しません。
